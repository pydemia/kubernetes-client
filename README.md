# kubernetes-client

High-level functional API for Kubernetes Resources and 3rd party CRDs,
based on the official kubernetes-client, and more.

The `kubernetes_client` package is restored from the files in the
`kubernetes-client` 0.1.8 wheel on PyPI. Its public import is
`from kubernetes_client import KubernetesManager`.

Build the package with `python -m build`. The build configuration was
reconstructed from the 0.1.0 source distribution and the 0.1.8 wheel
metadata; see [RECOVERY.md](RECOVERY.md) for the source and limits of the
recovery.
